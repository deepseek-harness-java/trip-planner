# 杭城出行规划台 · 使用说明

> 应用地址：`http://127.0.0.1:18081` ｜ DSH 控制台：`http://127.0.0.1:8090`
> 插件：`trip-assistant`（Java Native Plugin）

## 一、页面功能速览

| 区块 | 怎么用 |
|---|---|
| **出行规划** | 左上两个下拉选起终点（支持地铁站点 + 地标），选出发时段与偏好（最快/最便宜/少步行）→ 点「开始规划」，一次给出三种方案，橙框为最快推荐 |
| **打车计价** | 输入里程、选平峰/高峰 → 「估算」，三档车型并列对比，每张卡附价格明细 |
| **地铁线网图** | 3 条线 25 站，虚线橙圈 = 换乘站；点击任意站名会依次填入「出发地 → 目的地」 |
| **公交线路** | 输入站名（如「黄龙」）查经过该站的所有线路；留空显示全部 12 条 |
| **AI 出行助手** | 右下角悬浮球（呼吸光圈），大白话提问，流式回答 |

## 二、AI 助手能听懂的话

直接用自然语言说，助手会自动选择合适的工具（可连续组合）：

| 你说 | 助手调用的工具 |
|---|---|
| 「早八点从武林广场去良渚，最快怎么走？」 | `plan_trip` |
| 「龙翔桥到浙大坐地铁怎么换乘？」 | `metro_route` |
| 「黄龙体育中心附近有哪些公交？194 路经过哪些站？」 | `bus_query`（站查 + 线查） |
| 「打车 12 公里高峰期多少钱？」 | `taxi_estimate` |
| 「西湖边那个商场到良渚怎么走最省钱？」 | `station_search` → `plan_trip` |
| 「我拖着行李箱想少走路，杭州东站到西湖文化广场」 | `plan_trip`（少步行偏好） |

**回答纪律**：所有票价、耗时、站点均来自工具真实返回，查不到时助手会如实说明，不会编造。

## 三、计价口径

- **地铁**：¥2 起，按里程阶梯计价；换乘计 +4 分钟（步行+候车）
- **公交**：¥2~4，发车间隔 6~15 分钟，另计步行到站时间
- **打车**：起步价（经济 ¥12/优享 ¥16/商务 ¥24，含 3km）+ 里程费 + 时长费；早晚高峰溢价 ×1.25

## 四、常用运维命令

```bash
# 启动应用（显式端口，防环境变量劫持）
java -jar trip-app/target/trip-app-1.0.0-SNAPSHOT.jar --server.port=18081

# 探活
curl --noproxy '*' http://127.0.0.1:18081/
curl --noproxy '*' http://127.0.0.1:8090/api/harness/plugins

# 重置数据（内存数据重启即还原种子）
# 直接 Ctrl+C 停掉应用后重启即可
```

## 五、常见问题

**Q：AI 助手回复「联系不上」？**
A：检查 DSH 是否在运行（`curl --noproxy '*' http://127.0.0.1:8090/`），以及插件是否 ACTIVE（`/api/harness/plugins` 里 `trip-assistant` 状态）。页面其他功能不依赖 DSH，不受影响。

**Q：规划返回「暂无可用方案」？**
A：两地点跨出预置线网（如萧山机场以南）。先用页面搜索或 AI 助手定位附近的地铁站再规划。

**Q：模型怎么配？**
A：DSH 控制台 → 设置 → 模型设置，填模型地址 / 名称 / API Key（技能包 runtime jar 已内置默认渠道，可直接对话）。

## 六、已知边界

- 数据为教学模拟（真实杭州风格地名与里程量级），不用于真实出行决策
- 公交「按线路名查」支持「118 / 118路 / B1 / 194 区间」等写法，查不到时返回空列表
- 应用重启后用户写操作不保留（内存种子设计，便于演示）
